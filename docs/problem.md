# 課題

## 元の課題（MeetForMe より）

ハッカソンのキックオフ後、案はすぐ出たのに「どの案にするか」を決める場が開けず、時間だけが過ぎた。

- **予定が合わない**：授業・バイト・夜型/朝型。全員そろう時間を探すだけで数日かかる
- **声の大きい人の案になる**：集まっても、よく話す人の案に流れる
- **本音を言いにくい**：「その案は少し不安」が対面だと言い出せない

日程調整ツールは「いつ集まるか」は決めてくれるが、集まらずに「どの案にするか」を決める道具がない。

## 課題の言い換え（自分用）

> 少人数チームが、同期的に集まらずに、複数案から納得感のある1つを選ぶ

分解すると:

1. 案を集める
2. 各自の評価・懸念・譲れない条件を集める
3. 比較・統合する
4. 合意する（全員が「それでいい」と言える状態にする）

## 前提として確認したいこと

- [ ] 対象：ハッカソンチームに絞る？ サークル・授業のグループワークまで広げる？
- [ ] 人数：3〜5人想定？
- [ ] 期限：何時間〜何日で決めたい？
- [ ] 「決まらない」本当の原因は時間？ 合意形成のプロセス不在？ 責任を取りたくない？
