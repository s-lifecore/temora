# 試作・開発環境のみのもの

本番の利用者には見せない試作や、開発環境でだけ動くものの一覧。追加・変更・削除したら、このファイルも更新する。

## 料金画面の試作（`/pricing`）

| 項目               | 内容                                                                                                                                 |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------ |
| 状態               | 試作（課金は未実装）                                                                                                                 |
| 開き方             | ローカルの dev サーバーで `/pricing`（例: http://localhost:3000/pricing）                                                            |
| 本番での扱い       | `NODE_ENV === "production"` のとき `notFound()` で 404。検索エンジンにも載らない（`robots: noindex`）                                |
| トップからのリンク | なし                                                                                                                                 |
| 中身               | 会議ごとに項目（案の数・判定の精度・記録・通知・見た目など）を選ぶと、合計金額（税込・仮）が変わる。購入ボタンは押せない             |
| ファイル           | `src/app/pricing/page.tsx`（本番で隠す処理）、`src/app/pricing/configurator.tsx`（画面）、`src/lib/pricing.ts`（項目と金額のデータ） |
| 関連メモ           | [pricing-ideas.md](pricing-ideas.md)                                                                                                 |

### 注意

- 金額はすべて仮。試作の数字を本番の料金として表示しない
- 本番で表示する場合は、決済・特定商取引法の表記・税込の総額表示・返金ルールを用意してから（[pricing-ideas.md](pricing-ideas.md) と [tax-notes.md](tax-notes.md)）
- 検討中の変更（まだ反映していない）：個人プランから「参加人数」の項目を外し、法人・団体プラン（イベント単位・年額はその場で購入、大規模や請求書払いは相談）を別に設ける案。ハッカソンのチームは基本5人までのため

## テスト用の会議作成（`rooms:createForTest`）

| 項目           | 内容                                                                                                                             |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| 状態           | テスト専用                                                                                                                       |
| 中身           | ログインなしで会議を作る内部関数。画面やブラウザからは呼べず、`npx convex run rooms:createForTest '{...}'` で CLI からだけ呼べる |
| 使っている場所 | `scripts/smoke.mjs`                                                                                                              |
| 本番での扱い   | 本番デプロイにも存在するが、内部関数なので外部からは呼べない                                                                     |
| ファイル       | `convex/rooms.ts`                                                                                                                |

## 判定モデルの比較（`aiEval:compare`）

| 項目         | 内容                                                                                                                                             |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| 状態         | 開発用ツール                                                                                                                                     |
| 中身         | 正解付きの判定セットを、指定したモデルで判定させて結果を返す内部関数。`npx convex run aiEval:compare '{"models":["claude-haiku-5-5"],"runs":2}'` |
| 注意         | **本物の Claude API を呼ぶので費用がかかる**（Haiku なら数円、Opus を含めると数十円）                                                            |
| 本番での扱い | 内部関数なので外部からは呼べない                                                                                                                 |
| ファイル     | `convex/aiEval.ts`、結果のまとめは [model-eval.md](model-eval.md)                                                                                |

## 見本モード（`AI_MOCK=1`）

| 項目         | 内容                                                                             |
| ------------ | -------------------------------------------------------------------------------- |
| 状態         | 開発用の設定                                                                     |
| 中身         | Convex の環境変数 `AI_MOCK` が `1` のとき、AI を呼ばずに決まった見本の判定を返す |
| 本番での扱い | 本番では設定しない（`1` 以外・未設定なら本物の AI を使う）                       |
| ファイル     | `convex/model.ts`（`aiMock`）、`convex/ai.ts`                                    |
