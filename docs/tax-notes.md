# 税金まわりのメモ（Temora で売上が出た場合）

2026-11 時点で調べた内容。**制度は毎年のように変わり、調べた資料の間で数字が食い違うものもある**。実際に申告する前に、国税庁の最新の資料か、税務署・市区町村の窓口で確認すること。

前提：大学生（19〜22歳）の個人が、アルバイトとは別に Temora の売上を得る場合。

## 1. どの所得になるか

- Temora の売上から経費を引いた額が「所得」になる
  - 経費の例：Vercel・Convex・Anthropic（Claude API）の利用料、Stripe の手数料、ドメイン代
- 規模が小さいうちは**雑所得**（業務に係る雑所得）になるのが基本
- 継続的で規模が大きく、帳簿もつけていれば**事業所得**になりうる。目安として「年300万円以上で帳簿があれば概ね事業所得」とする解説があるが、一律の基準はなく、実態で判断される
- 事業所得にして青色申告（最大65万円の控除）を使うには、開業届・青色申告の承認申請・複式簿記などが必要（細かい要件は未確認）

## 2. 確定申告が必要か

| 状況                                                     | 所得税                                                              | 住民税                                                      |
| -------------------------------------------------------- | ------------------------------------------------------------------- | ----------------------------------------------------------- |
| アルバイト先で年末調整済み＋ Temora の所得が年20万円以下 | 原則、確定申告は不要                                                | **20万円以下でも申告が必要**（市区町村に、原則3月15日まで） |
| アルバイト先で年末調整済み＋ Temora の所得が年20万円超   | 確定申告が必要                                                      | 確定申告すれば住民税の申告も兼ねる                          |
| アルバイトなし（年末調整なし）                           | 合計所得が基礎控除以下なら税額は0（還付や控除を受けるなら申告する） | 市区町村の基準を確認                                        |

- **基礎控除**：令和7年分から段階制になり、合計所得132万円以下なら95万円（改正前は48万円）。132万円超336万円以下は88万円だが、**令和9年分以後は58万円に戻る予定**
- **給与所得控除の最低額**：55万円から65万円に上がった（アルバイト代の計算に影響）

## 3. 学生だからこそ注意すること

### 勤労学生控除（27万円）が使えなくなる

- 要件のひとつが「**勤労以外の所得が10万円以下**」。Temora の所得（雑所得）が年10万円を超えると、この控除は受けられなくなる
- 合計所得の上限は、資料によって75万円・85万円・89万円と記載が分かれている（年分による違いの可能性）。**要確認**

### 親の扶養（親の税金が増えることがある）

19〜22歳の子の場合、子の**合計所得**（アルバイトの給与所得＋ Temora の所得）で、親が受けられる控除が変わる。

| 子の合計所得        | 親が受けられる控除                                             |
| ------------------- | -------------------------------------------------------------- |
| 58万円以下          | 特定扶養控除（63万円）                                         |
| 58万円超123万円以下 | 特定親族特別控除（所得が増えるにつれて63万円から段階的に減る） |
| 123万円超           | どちらも受けられない                                           |

- 令和8年分は基準が「62万円超」になったとする解説もあり、**要確認**
- 扶養の範囲を超えそうなら、事前に親と相談する

## 4. 消費税・インボイス

- 消費税は、**前々年の課税売上高が1,000万円以下**なら原則免税（ただし前年1〜6月の売上などが1,000万円を超えると免税にならない）。当面は気にしなくてよい規模
- **インボイス**：大学や企業から、適格請求書（インボイス）を求められることがある。免税事業者のままでは発行できない
  - 登録すると消費税の申告が必要になる。負担を軽くする「2割特例」（令和8年分まで）と、個人向けの「3割特例」（令和9・10年分）がある
  - 法人・団体プランの請求書払いを始めるときに、登録するかを判断する

## 5. 今からやっておくこと

- 売上（Stripe の売上レポート）と経費（各サービスの請求書・領収書）の記録を残す
- 年の途中で「所得が10万円・20万円・58万円を超えそうか」を確認する
- 申告の時期（2〜3月）より前に、税務署か市区町村の窓口で相談する
