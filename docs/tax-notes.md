# 税金まわりのメモ（Temora で売上が出た場合）

2026-11 時点で調べた内容。**制度は毎年のように変わり、調べた資料の間で数字が食い違うものもある**。実際に申告する前に、国税庁の最新の資料か、税務署・市区町村の窓口で確認すること。

前提：大学生（19〜22歳）が**個人事業主として開業し**、アルバイトとは別に Temora の売上を得る場合。

## 1. 開業の手続き

| 手続き                                 | 期限（目安）                                                                                  | 内容                           |
| -------------------------------------- | --------------------------------------------------------------------------------------------- | ------------------------------ |
| 開業届（個人事業の開業・廃業等届出書） | 開業から1か月以内                                                                             | 税務署に出す。e-Tax でも出せる |
| 青色申告承認申請書                     | 開業日から2か月以内（1月16日以後に開業した場合）。翌年から青色にするなら、その年の3月15日まで | 出さないと白色申告になる       |

- 期限は解説記事ベースの記載もあるので、提出前に国税庁の案内で確認する
- 事業用の銀行口座とクレジットカードを分けておくと、帳簿づけが楽になる

## 2. どの所得になるか

- 売上から経費を引いた額が「所得」になる
  - 経費の例：Vercel・Convex・Anthropic（Claude API）の利用料、Stripe の手数料、ドメイン代、開発用の機材（金額によっては減価償却）
- 開業して**帳簿をつけて保存していれば、事業所得**として扱われやすい
- 判定は「社会通念上、事業と呼べる規模か」の実態で決まる。**帳簿の保存がないと、業務に係る雑所得**になる（所得税基本通達35-2）
- 「収入300万円以下は雑所得」という基準は、2022年の改正案にはあったが、最終的な通達では削除された。300万円以下でも事業所得になりうる

## 3. 青色申告

| 控除額 | 要件                                                                                 |
| ------ | ------------------------------------------------------------------------------------ |
| 65万円 | 複式簿記で記帳し、貸借対照表を付けて、**e-Tax で申告**（または優良な電子帳簿の保存） |
| 55万円 | 複式簿記で記帳して、書面で申告（**令和8年分まで**）                                  |
| 10万円 | 簡易な記帳                                                                           |

- **令和9年分以後は、書面で申告した場合の控除の上限が10万円になる予定**。最初から会計ソフト＋ e-Tax で65万円を狙うのがよい
- 改正後は65万円または75万円になるという資料もあり、細部は**要確認**
- 青色申告特別控除は所得を減らすので、次の「扶養」の判定でも有利に働く

## 4. 確定申告

- 個人事業主として事業所得があるなら、**毎年確定申告する**前提で考える（期間は原則2月16日〜3月15日）
  - 「給与以外の所得が20万円以下なら申告不要」という決まりは所得税だけの話で、青色申告特別控除を受けるには申告が必要
  - 確定申告をすれば、住民税の申告も兼ねる
- **基礎控除**：令和7年分から段階制になり、合計所得132万円以下なら95万円（改正前は48万円）。132万円超336万円以下は88万円だが、**令和9年分以後は58万円に戻る予定**
- **給与所得控除の最低額**：55万円から65万円に上がった（アルバイト代の計算に影響）
- **個人事業税**：事業所得から事業主控除（年290万円）を引けるので、この規模ならまずかからない

## 5. 学生だからこそ注意すること

### 勤労学生控除（27万円）

- 要件は「勤労による所得があること」「合計所得が一定以下」「勤労以外の所得が10万円以下」
- 解説記事では、**事業所得も「勤労による所得」に含まれる**とされている（不動産や配当のように労働と関係ない所得が「勤労以外」）。ただし国税庁のページで明記は確認できていないので**要確認**
- 合計所得の上限は、資料によって75万円・85万円・89万円と記載が分かれている（年分による違いの可能性）。**要確認**

### 親の扶養（税金）

19〜22歳の子の場合、子の**合計所得**（アルバイトの給与所得＋事業所得）で、親が受けられる控除が変わる。

| 子の合計所得        | 親が受けられる控除                                             |
| ------------------- | -------------------------------------------------------------- |
| 58万円以下          | 特定扶養控除（63万円）                                         |
| 58万円超123万円以下 | 特定親族特別控除（所得が増えるにつれて63万円から段階的に減る） |
| 123万円超           | どちらも受けられない                                           |

- 令和8年分は基準が「62万円超」になったとする解説もあり、**要確認**
- 扶養の範囲を超えそうなら、事前に親と相談する

### 親の扶養（健康保険）

- 親の健康保険の被扶養者でいられるのは、19〜22歳なら**年間収入150万円未満**（2025年10月以降の認定から。それ以前は130万円未満）
- 事業収入をどう数えるか（売上か、経費を引いた額か）は**保険者によって違う**。親の勤務先の健康保険組合や協会けんぽに確認する
- 被扶養者から外れると、自分で国民健康保険に入る必要が出る

### 国民年金

- 20歳以上は国民年金に加入する。学生は「学生納付特例」で納付を猶予できるが、本人の所得に上限がある。**要確認**

## 6. 消費税・インボイス

- 消費税は、**前々年の課税売上高が1,000万円以下**なら原則免税（ただし前年1〜6月の売上などが1,000万円を超えると免税にならない）。当面は気にしなくてよい規模
- **インボイス**：大学や企業から、適格請求書（インボイス）を求められることがある。免税事業者のままでは発行できない
  - 登録すると消費税の申告が必要になる。負担を軽くする「2割特例」（令和8年分まで）と、個人向けの「3割特例」（令和9・10年分）がある
  - 法人・団体プランの請求書払いを始めるときに、登録するかを判断する

## 応援（GitHub Sponsors）で受け取ったお金

- 扱いは自分で自由に選べるものではなく、**税法上、受け取り方の実態で決まる**（申告は自分で区分して行うが、誤っていれば税務署から直されることがある）
- 一般的な扱いの例：
  - Temora という事業への応援として継続的に受け取る → 事業の収入（事業所得）とする考え方が自然
  - 個人から、事業と関係なく見返りなしでもらう → 贈与（もらった側に贈与税。年110万円までは非課税）
  - 会社から受け取る → 贈与税ではなく所得税の対象（一時所得など）
- GitHub Sponsors で Temora のページから受け取る応援は事業に結びついているので、**事業の収入として申告するのが無難**。最初に受け取った年の申告前に、税務署の相談窓口で確認する（**要確認**）
- 入金は Stripe 経由で振り込まれる。購入（Stripe）と応援（GitHub Sponsors）で入金元が分かれるので、帳簿では両方を記録する
- GitHub と Stripe の手数料は、経費として記録する

## 7. 今からやっておくこと

- 課金を始める前に、開業届と青色申告承認申請書を出す（期限に注意）
- 会計ソフトを決めて、売上（Stripe の売上レポート）と経費（各サービスの請求書・領収書）を記帳する
- 年の途中で、合計所得が扶養の基準（58万円・123万円）や、健康保険の基準（年間収入150万円）を超えそうか確認する
- 申告の時期（2〜3月）より前に、税務署か市区町村の窓口で相談する
