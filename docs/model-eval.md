# 判定モデルの比較（2026-11-21）

○△✕ の判定をどのモデルで行うかを決めるための比較。`convex/aiEval.ts`（`npx convex run aiEval:compare`）で再実行できる。

## 方法

- 場面：ハッカソン（4案×5軸）、勉強会（3案×4軸）、新歓（3案×4軸）、LT会（2案×3軸。△が正解のマスを含む）
- 人が見て答えが明らかなマスに正解を付け、正解率を測る
- 同じ入力を複数回判定し、答えのぶれを見る
- 費用は入出力トークン数と料金表から計算（1ドル150円で換算）

## 1回目：3モデルの比較（調整前の指示文、LT会以外の3場面×2回）

|                 | Opus 5.5 | Sonnet 5.5 | Haiku 5.5 |
| --------------- | -------- | ---------- | --------- |
| 正解率          | 46/46    | 45/46      | 42/46     |
| ○と✕の取り違え  | 0        | 0          | 0         |
| 2回の一致       | 43/44    | 41/44      | 43/44     |
| 1回あたりの時間 | 16.0秒   | 7.3秒      | 11.1秒    |
| 1回あたりの費用 | 約5円    | 約1.5円    | 約0.17円  |

Haiku の外れは4マスとも「○のはずが△」。「書かれていないことは推測せず△」に忠実すぎた。

## 2回目：Haiku で指示文を調整（4場面×3回）

調整内容：「書かれた内容から常識的に読み取れるなら○か✕、どちらとも読み取れないときだけ△」。例には比較用の場面と別のものを使った。

|                 | Haiku 5.5                                           |
| --------------- | --------------------------------------------------- |
| 正解率          | 87/87（△が正解のマスを含む）                        |
| ○と✕の取り違え  | 0                                                   |
| 3回の一致       | 92/100（ぶれたのは主観的な軸での「△か○／✕か」だけ） |
| 1回あたりの時間 | 8.5秒                                               |
| 1回あたりの費用 | 約0.15円                                            |

## 結論

Haiku 5.5 を標準にする。会議1つあたり（やり直しを含めても）1円未満。試したのは4場面だけなので、公開後も実際の判定に違和感がないかを見ていく。

## 比較中に見つかった問題

Haiku が案の記号を `I1` ではなく `I1 学食の混雑予報` のように返すことがあった。アプリ本体でも判定が失敗する原因になるため、記号部分だけを取り出して照合するように直した。
