# 料金プランの案（検討メモ・未実装）

当面は無料プランのみで運用する。ここは有料化を考えるときのためのメモ。金額はすべて仮。

## 前提

- AI（Haiku 5.5）の費用は会議1つあたり1円未満。上位モデルでも多くて20円程度
- Temora は「ときどき・単発」で使われる（ハッカソン、新歓、勉強会のテーマ決めなど）。毎月払い続ける個人サブスクとは相性が悪い
- 課金で回収したいのは AI 代ではなく、「払ってでも欲しい価値」

## 払い方の種類

| 払い方                | 中身                                 | 相性                                 |
| --------------------- | ------------------------------------ | ------------------------------------ |
| 都度払い（1会議ごと） | アップグレードしたい会議だけ払う     | ◎                                    |
| 回数券（クレジット）  | 「5会議分 ¥1,000」のようにまとめ買い | ○                                    |
| 個人サブスク          | 毎月・毎年払って上限を広げる         | △ 使わない月も払うので解約されやすい |
| 団体サブスク（年額）  | サークル・ゼミ・企業単位で契約       | ○ 定期的に決めごとがある団体に       |
| 買い切り（永久）      | 一度払えばずっと使える               | △ 運営費は続くので売り手が損しやすい |
| 従量課金              | 使った分だけ後払い                   | ✕ 金額が読めない                     |
| 寄付・応援            | 機能は全部無料                       | ○ 最初の一歩として手軽               |

## プランの分け方（試作に反映済み）

- **個人プラン**：チーム・ゼミ・少人数の企画向け。会議ごとに構成を選ぶ（下記）。参加は12人で固定（ハッカソンのチームは基本5人までなので十分）
- **法人・団体プラン**：ハッカソンや勉強会の運営、サークル、ゼミ、授業、企業向け。30人・100人規模で使うのは、運営が全チームに会議を用意して代表に権限を渡す場面なので、こちらで扱う

| 法人・団体プラン | 価格（仮・税込）                   | 申し込み方                                 |
| ---------------- | ---------------------------------- | ------------------------------------------ |
| イベント         | ¥5,000 / 1イベント（20チームまで） | その場でカード払い                         |
| 年額             | ¥30,000 / 1年（イベント数無制限）  | その場でカード払い                         |
| 大規模・特別対応 | ご相談                             | 相談（20チーム超、請求書払い、独自の要望） |

共通の機能：チームごとの会議の一括作成、各チームの代表へのホスト権限の譲渡、運営の管理画面、1会議の人数の拡大、ロゴ・色、記録の書き出し

## 個人プラン：会議ごとの「構成を選ぶ」課金（Apple のカスタマイズ購入に近い形）

標準構成は無料（¥0）。会議を作るときに、項目ごとに性能を選ぶと合計金額がその場で変わる。迷う人のために、組み合わせ済みの「おすすめ構成」も並べる。

試作画面：開発中の環境で `/pricing` を開く（本番では表示されない）。項目と金額は `src/lib/pricing.ts`。

### 項目と料金（仮）

| 項目          | 標準（¥0）        | 上げると                                              |
| ------------- | ----------------- | ----------------------------------------------------- |
| 1人あたりの案 | 5つまで           | 10個まで +¥100                                        |
| 判定の精度    | 標準（Haiku 5.5） | 高精度（Sonnet 5.5）+¥100 / 最高精度（Opus 5.5）+¥300 |
| 決定の記録    | 30日保存          | 1年保存＋PDF・CSV 書き出し +¥200                      |
| 通知          | なし              | 締切前のリマインド（メール・Discord）+¥100            |
| 見た目        | 4種のデザイン     | 団体のロゴ・色 +¥200                                  |

### おすすめ構成（仮）

| 構成               | 中身                        | 価格 |
| ------------------ | --------------------------- | ---- |
| ゼミ・少人数       | 標準のまま                  | 無料 |
| ハッカソンのチーム | 高精度・締切前のリマインド  | ¥200 |
| 大事な決定         | 最高精度・1年保存＋書き出し | ¥500 |

### よい点

- 必要な分だけ払える
- 費用と値段の関係が素直（上位モデルでも AI 代は値段に十分収まる）
- 判定の精度を上げても、会議の中では全員が同じモデルなので平等さは崩れない

### 気をつけること

- 項目は5〜6個までにして、おすすめ構成を先に見せる（選択肢が多いと迷う）
- 会議の途中で上げたくなる場合に、差額だけ払って上げられるようにする
- 少額決済の手数料（Stripe は売上の数％）で、¥100 単位の上乗せが成り立つか確認する
- 上位モデルを買ったのに AI が止まって手動判定になった場合の返金ルールを決める
- 金額は税込みの総額で表示する

## 損益分岐（作業時間は含めない）

### 月の費用

| 費用                  | 金額                  | 備考                                                                       |
| --------------------- | --------------------- | -------------------------------------------------------------------------- |
| Vercel Pro            | 約3,000円（月20ドル） | 課金を始めると商用利用のため必要になるはず。課金前は無料プランのままでよい |
| 無料で使われる分の AI | 1会議あたり約1〜3円   | 月300会議なら約300〜900円                                                  |
| Convex                | 0円                   | 無料枠を超えたら有料（月25ドル程度）                                       |

固定費は月3,000〜4,000円と見ておく。

### 1件売れたときに残る額（手数料約3.6%と AI 費用を引いたもの）

| プラン                             | 価格（仮） | 残る額                          | 月の固定費を賄うのに必要な数 |
| ---------------------------------- | ---------- | ------------------------------- | ---------------------------- |
| 個人：ハッカソンのチーム           | ¥200       | 約190円                         | 約16〜21件                   |
| 個人：大事な決定（最高精度＋記録） | ¥500       | 約460円                         | 約7〜9件                     |
| 法人・団体：イベント（20チーム）   | ¥5,000     | 約4,300〜4,800円                | 約1件                        |
| 法人・団体：年額                   | ¥30,000    | 約28,900円（月あたり約2,400円） | 2件で1年分                   |

20チームのイベントで AI にかかる費用は、標準（Haiku）で約20〜60円、全部を最高精度（Opus）にしても約100〜500円。判定は1回約0.15円（実測）、「AI で型にそろえる」は1回約0.05円（推定）で計算した。

**結論**：損益分岐は「月にイベントプラン1件」か「個人のアップグレード十数件」。運営向けのプランが分岐を左右する。

## お金の受け取り口

| 用途                                                 | 使うもの        | 状態                                                                                            |
| ---------------------------------------------------- | --------------- | ----------------------------------------------------------------------------------------------- |
| 購入（個人プランのアップグレード、法人・団体プラン） | Stripe          | 未着手。購入を始めるときに、特定商取引法の表記・返金ルール・税込みの総額表示を用意する          |
| 応援・寄付                                           | GitHub Sponsors | 準備中（Stripe との紐づけ中）。公開されたら URL を Vercel の `NEXT_PUBLIC_SUPPORT_URL` に入れる |

## 広告・寄付と「商用利用」の関係（2026-11 時点）

| 収益化の方法         | Vercel 無料（Hobby）プラン | 備考                                                                           |
| -------------------- | -------------------------- | ------------------------------------------------------------------------------ |
| 寄付・応援リンク     | そのまま使える             | Vercel の Fair Use Guidelines で「寄付を募ることは商用利用に当たらない」と明記 |
| 広告（AdSense など） | 商用扱い。Pro 以上が必要   | 同ガイドラインで商用利用の例に「広告を載せること」が挙げられている             |
| 有料プラン           | 商用扱い。Pro 以上が必要   |                                                                                |

- Convex の無料（Starter）プランは「個人のプロジェクトや試作向け」と説明されている。商用利用の可否は、収益化の前に利用規約で確認する
- 広告を付けるなら、プライバシーポリシーの掲載（AdSense の条件）と、外部送信規律（電気通信事業法）への対応が必要になりうる
- 「公平に決める」サービスなので、判定画面の近くの広告は信頼性を損なうおそれがある
- Pro の固定費（月約3,000円）が必要になるのは広告でも有料プランでも同じ。回収の効率では有料プランのほうがよい

参考：[Vercel Fair Use Guidelines](https://vercel.com/docs/limits/fair-use-guidelines)、[Vercel Hobby プラン](https://vercel.com/docs/plans/hobby)、[Convex の料金](https://www.convex.dev/pricing)

## 課金を始める前の確認事項

- Vercel の無料（Hobby）プランは商用利用が禁止。有料化したら Pro への切り替えが必要になるはず
- 特定商取引法に基づく表記が必要（個人の場合の住所・電話番号の扱いを確認）
- 決済は Stripe が有力（本人確認と口座登録が必要）
- 個人事業主として開業する前提。開業届・青色申告・税金まわりは [tax-notes.md](tax-notes.md) を参照
- いずれも始める時点で最新の規約と制度を確認する

## 進め方

1. 無料のまま運用し、使われ方（会議の作成数、人数、上限に当たった回数）を数える
2. 上限に当たる人が出てきたら、何に困っているかを聞いて有料にする価値を決める
3. それまでは「応援する」リンクだけ置いて反応を見る

## 実装するときの方針

今の `src/lib/plans.ts`（無料プランの上限表）を、会議ごとに「どの項目をどこまで上げたか」を記録し、そこから上限を決める形に広げる。
